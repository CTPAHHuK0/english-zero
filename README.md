# Английский с нуля

Мобильное веб-приложение (PWA) для изучения английского с самого начала — даже если вы не умеете читать латинские буквы.

- **59 станций** в 5 зонах: звуки и буквы → чтение слов → фразы → грамматика → прошлое и будущее → живые разговоры.
- ~330 слов, ~110 фраз, ~75 предложений, 10 правил-шаблонов (355 вариантов предложений), 12 пар похожих звуков, 15 историй про Анну и 6 диалогов с ролевой игрой.
- 16 типов упражнений: слушать, читать, выбирать картинку, собирать слово и фразу, вставлять пропуск, различать похожие звуки, говорить в микрофон, записывать себя и сравнивать с образцом.
- Объяснение каждой ошибки, режим «Не могу слушать», перенос прогресса QR-кодом или файлом.
- Разговор с ИИ (кафе, аэропорт, отель…) — в версии на claude.ai.
- Интервальные повторения по алгоритму FSRS, серия дней, дневная цель, награды.
- Работает без интернета (после первого открытия) и устанавливается на экран телефона.

Почему всё устроено именно так — в [docs/research.md](docs/research.md).

**Открыть приложение:** https://ctpahhuk0.github.io/english-zero/ (на Android: меню Chrome ⋮ → «Установить приложение»).

## Как открыть

### На компьютере

Самый простой способ — открыть файл `dist/english-zero.html` в Chrome или Edge (двойной клик). Это всё приложение в одном файле.

Для разработки запустите локальный сервер в папке проекта и откройте http://localhost:8765:

```bash
python -m http.server 8765
```

### На телефоне Android (полноценная установка)

Приложению нужен адрес в интернете (https), тогда работают установка на экран, офлайн-режим и микрофон. Бесплатный вариант — GitHub Pages:

1. Зарегистрируйтесь на github.com и создайте новый публичный репозиторий.
2. Загрузите в него все файлы проекта (кнопка «Add file → Upload files»).
3. В репозитории откройте Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
4. Через минуту появится адрес вида `https://ваш-логин.github.io/имя-репозитория/`. Откройте его в Chrome на телефоне.
5. Меню Chrome (⋮) → «Установить приложение» или «Добавить на главный экран».

Озвучка записана заранее и работает без интернета. Если в профиле выбран «Голос устройства» и звука нет: Настройки Android → Специальные возможности → Синтез речи (или «Преобразование текста в речь») → Google → установите «English (United States)».

### Перенос прогресса

Прогресс хранится в браузере на конкретном устройстве. Чтобы перенести его, откройте Профиль → Перенос прогресса:

- **QR-код:** на компьютере нажмите «Показать QR-код», на телефоне — «Сканировать QR-код» и наведите камеру на экран (коды сменяются, держите камеру, пока не соберутся все). Сканирование работает в Chrome на Android.
- **Файлом:** «Отправить файлом» откроет меню «Поделиться» (например, отправить себе в Telegram), на другом устройстве — «Загрузить из файла».
- **Текстом:** «Копия текстом» → скопировать и вставить на другом устройстве.

## Как превратить в приложение для Google Play

Проект уже является PWA, поэтому есть два пути:

- **Trusted Web Activity** (проще): инструмент [Bubblewrap](https://github.com/GoogleChromeLabs/bubblewrap) собирает APK/AAB из адреса сайта на GitHub Pages.
- **Capacitor** (больше возможностей, например уведомления-напоминания): создайте проект Capacitor и укажите эту папку как `webDir`.

## Как добавлять материал

Контент записывается коротко в файлах `js/content/units-*.js`:

```js
W('cat|кот|🐱')                                  // слово | перевод | картинка
P('Thank you!|Спасибо!|🙏')                      // фраза целиком
S('She [is] a doctor.|Она врач.', 'am,are')       // предложение; [..] — пропуск, затем неверные варианты
MP('ship|корабль|🚢', 'sheep|овца|🐑', 'подсказка') // пара похожих по звучанию слов
```

Новая станция — это вызов `D.unit({...})` в нужном месте списка. Уроки делятся автоматически по 4 элемента или задаются явно через `lessons`.

После изменений перезапишите озвучку для новых фраз и пересоберите однофайловую версию (см. ниже).

## Озвучка

Все слова, фразы и истории записаны заранее нейросетью [Kokoro](https://github.com/thewh1teagle/kokoro-onnx) (открытая лицензия Apache-2.0) двумя американскими голосами: женским и мужским. Записи лежат в папке `audio/`. Голос можно сменить в профиле; там же можно переключиться на синтезатор устройства. Если какой-то фразы нет в записях, приложение само произнесёт её синтезатором.

Чтобы озвучить новые фразы после изменения контента:

```bash
pip install kokoro-onnx soundfile
```

Скачайте `kokoro-v1.0.onnx` и `voices-v1.0.bin` со страницы релизов kokoro-onnx в отдельную папку, затем:

```bash
node tools/audio-inventory.js > inventory.json
```

```bash
python tools/make_audio.py --inventory inventory.json --model-dir путь/к/папке/с/моделью
```

Уже записанные фразы берутся из кэша `.audio-cache/`, поэтому повторная запись быстрая.

```bash
node tools/build.js
```
